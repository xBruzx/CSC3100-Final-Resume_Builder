# Resume Builder final project!
Welcome to my resume builder! Making this for a webdev class a final project where we have to incorperate an AI API key to help make changes to a users resume that they enter in. The AI will make suggestions based upon what their resume says, and or look to add things based on their job history/academic awards.

# Project
This project I will be using HTML, CSS (Bootstrap), and JavaScript to develope the front end for the app.

# Project Outline
The prject is a simple resume builder that uses a Gemini to make recommendedations to a users resume based off the information they enter in plus what they already have in their resume if they choose to upload one, or alternatively build a brand new resume from scratch.
